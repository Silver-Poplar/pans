## 顶层 CMakeLists.txt

编译器在 `project()` 之前写死成 `/usr/bin/gcc`、`/usr/bin/g++`，配 `CACHE ... FORCE` 压掉已有缓存，省得各人环境不一致。写在 project 前是必须的，编译器定下来就改不了。

标准 C++20，后面协程要用。开了 `CMAKE_CXX_EXTENSIONS`，实际命令行是 `-std=gnu++20`。再加 `CMAKE_CXX_STANDARD_REQUIRED ON`，不支持就直接报错，不悄悄降到 17 让协程编译失败。

include 了 `GNUInstallDirs` 和 `CMakePackageConfigHelpers`。后者目前只是 include，包配置还没写。

三个开关 `PANS_BUILD_EXAMPLES` / `TESTS` / `TOOLS`，默认都开。EXAMPLES 现在没有对应的子目录。

构建类型：单配置生成器没指定就兜底 Debug，顺手给 cmake-gui 配上可选值。

并行编译这块省事——配置期查逻辑核数，按 1.5 倍设 `CMAKE_BUILD_PARALLEL_LEVEL`，之后 `cmake --build build` 不用手敲 `-j`。本机 4 核算出 6，和 CMakeCache 里的值对得上。

末尾 `include(cmake/pansOptions.cmake)` 得在 `add_subdirectory(pans)` 前面，pans 要链接它。

## cmake/pansOptions.cmake

把编译链接选项收进 INTERFACE 库 `pans_options`，谁链接谁继承。比 `add_compile_options` 好在有作用域、能传递，不用在每个 target 上抄一遍 flag。

通用告警 `-Wall -Wextra -Wpedantic`。另外两个：

- `-fno-strict-aliasing`：网络代码要在 `sockaddr` 和字节缓冲之间做类型双关，开严格别名优化容易出那种看着莫名其妙的崩溃
- `-Wno-builtin-macro-redefined`：日志宏里会重定义 `__FILE__`，用来裁掉源码根路径只留相对路径

`-fPIC` 和 `-rdynamic` 都套了生成器表达式，限定 Linux + GCC/Clang。`-rdynamic` 是给栈回溯用的，崩溃时 `backtrace_symbols` 才能打出函数名而不是裸地址。这里注意 pans 是 STATIC 库，用 `ar` 打包不走链接，所以 `link.txt` 里看不到它，只在链接可执行文件时才生效。

Debug / Release 分开：

- Debug 定义 `PANS_DEBUG`，加 `-O0 -g3 -ggdb`。`-g3` 带宏定义，GDB 里能 `info macro`
- Release 和 RelWithDebInfo 都带 `-DNDEBUG -O2 -fno-omit-frame-pointer`。留帧指针是给 perf 和火焰图用的，代价是少一个寄存器

覆盖率开关 `ENABLE_COVERAGE` 默认 OFF，开了只在 Debug 下加 `--coverage`，编译和链接都要加。

`target_compile_options(pans_options INTERFACE ...)` 调了 4 次。`target_*` 是追加语义，拆开写和写一段完全等价，只是按用途分组后好读。

## pans/CMakeLists.txt

`file(GLOB_RECURSE ... CONFIGURE_DEPENDS)` 递归收 cpp 和头文件。`CONFIGURE_DEPENDS` 让每次构建重新扫文件列表，加新 cpp 不用重跑 cmake。

这里有个坑：一个源文件都没有时 `add_library` 直接报 `No SOURCES given to target`。所以有了 `pans/pans.not.empty.file.cpp`——一个 0 字节的占位文件，专门让 GLOB 结果非空。等有真实 cpp 了就能删。

头文件路径定下了目录约定：`include/` 对外公开，`src/` 私有。公开的那份拆成 BUILD_INTERFACE 和 INSTALL_INTERFACE，保证装完以后 include 路径也是对的。实测命令行是 `-I.../pans/include -I.../pans/src`，但这两个目录现在还不存在；CMake 不会因为目录不存在报错，第一次写代码前得先建。

`target_compile_features(pans PUBLIC cxx_std_20)` 和顶层标准双保险，即使别处改了全局标准，链接 pans 的一方也被要求 C++20。

`-Werror` 只加在主库上，测试和工具不加。库代码要求干净，测试里允许临时性警告。

install 用 GNUInstallDirs 的变量而不是硬编码 `lib` / `bin`，64 位系统上能处理 `lib64` 的差异。`install(DIRECTORY include/ ...)` 指向的目录还不存在，装的时候会失败。

## docs/README.md

根目录的 README 删了，项目说明挪到 docs 下，顺带补了一份代码规范：常量全大写，类名首字母大写驼峰，非静态成员函数首字母小写驼峰、静态成员函数首字母大写，非静态成员变量 `m_` 前缀、静态的 `s_` 前缀，全局函数首字母大写，局部变量和参数全小写加下划线。

把类成员和局部变量用命名风格强行分开，长函数里一眼能看出 `conn_id` 和 `m_connId` 不是一个东西，省掉一类 shadow 和误改成员的 bug。
